## 待实施契约

命名空间 `GameSDK`，基类 `public abstract class Singleton<T> where T : Singleton<T>`。

| 入口 | 语义 |
|---|---|
| `public static T Instance { get; }` | 按需创建、初始化，返回就绪实例；失败抛错，不返回半成品。 |
| `public static void ReleaseInstance()` | 仅释放当前实例，不调用 `Instance` 或触发创建。 |
| `protected virtual void OnInitialize()` | 创建后调用一次，取得实例资源。 |
| `protected virtual void OnRelease()` | 释放实例资源，含初始化失败前已取得者。 |

具体类以自身为 `T`，非抽象、private 无参构造且无 public 构造；基类 protected 构造。首次创建先校验构造合约，再受控反射创建，不用 `new()` 约束。泛型基类无法在编译期强制派生类私有构造，仍须静态检查具体类型。构造与字段初始化不得获取需回收的外部资源。

## 生命周期实现

每类型独立维护 `Empty → Initializing → Ready → Releasing → Empty`，与每实例的钩子执行记录分开。已释放对象永久失效，下轮新建。短锁只保护状态转换，构造与钩子在锁外执行；业务并发及旧引用使用由消费方负责。

1. **获取**：`Empty` 先转 `Initializing`，再构造并调用 `OnInitialize`，成功才登记 `Ready` 并返回。`Ready` 复用原实例；`Initializing`／`Releasing` 抛 `InvalidOperationException`，并发与重入同规则。
2. **释放**：`Ready` 先转 `Releasing`、撤销获取资格，再调用一次 `OnRelease`；`finally` 清本轮登记并回 `Empty`，不因钩子报错遗漏收尾。`Empty`／`Releasing` 无操作，`Initializing` 抛 `InvalidOperationException`；均不主动重建。
3. **失败**：构造失败回 `Empty`，不调用释放钩子；一旦进入初始化钩子，失败须转 `Releasing`、尝试一次 `OnRelease` 后收尾。单个失败保留原始异常；初始化与清理均失败时，用 `AggregateException` 按原始、清理顺序保留二者。反射包装不替代构造原始异常；主动释放异常也在收尾后抛出，下次获取可重试。

收尾只处理本轮捕获实例，以引用身份核对登记，不经静态获取入口清理资源。具体类型负责逐项清理、不遗漏资源；框架不接管业务资源或使用期限。

## 验证

静态检查构造合约及程序集隔离；EditMode 测试观察具体单例的资源和钩子计数：

| 触发 | 预期 |
|---|---|
| 同类型连续获取，再获取另一类型 | 前者引用相同、初始化一次；类型间状态、资源、释放互不影响。 |
| 构造失败；初始化取得部分资源后失败 | 均无可用登记、可重试；前者不调释放钩子，后者清理一次、无资源遗留。 |
| 初始化与清理均报错；主动释放钩子报错 | 保留约定异常，均回 `Empty`，不重复调用同一实例的释放钩子。 |
| 构造/初始化内重入获取或释放；释放内重入获取或释放 | 忙碌获取、初始化中释放抛错；释放中再释放无操作。以可控阻塞钩子验证并发同结果，且调用钩子时不持有框架状态锁。 |
| 空状态释放；成功释放两次后再获取 | 释放均不创建、旧实例仅清理一次；随后获取新实例，旧引用不影响新登记。 |
