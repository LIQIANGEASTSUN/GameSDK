# Singleton 需求

提供普通类与 Unity `MonoBehaviour` 两类单例，保证创建、唯一性与释放一致。

| AC | 要求与验收 |
|---|---|
| AC-01 | 具体单例使用私有构造，不暴露 public 构造，消费方不能直接 new。 |
| AC-02 | 同类型获取复用唯一有效实例，不同类型隔离；初始化与释放期间禁止获取半成品或重建。 |
| AC-03 | Mono 优先复用已有组件，含非活动者且不擅自激活；缺失才创建 GameObject 并 AddComponent。重复组件不初始化；编辑模式及退出门禁生效后拒绝获取。 |
| AC-04 | 提供显式释放入口及受保护的初始化／释放钩子。每实例初始化一次，成功才可用；一旦开始初始化，正常释放或初始化失败均清理一次。失败须报错并撤销框架登记，保留初始化与清理异常，后续获取可重试。 |
| AC-05 | 重复释放安全且不创建，下一次获取才可新建；已释放实例不复用，其框架收尾及迟到回调不得清除新登记或误释放新实例资源。 |
| AC-06 | 使用期限、跨场景保留由使用者决定，底层不干预宿主层级；清理限于自身所有权，不误删使用者宿主及其他组件。 |

从未激活的预置组件经获取初始化后，使用者须先显式释放再外部销毁或卸载；否则后续受控入口发现失效时才尝试补清理，无法保证及时回调。接口、状态与流程见[普通类 Task](Tasks/实现普通类单例.md)和[组件 Task](Tasks/实现MonoBehaviour单例.md)。
