# Device 设备服务需求

为跨项目消费者提供设备标识、广告标识、广告跟踪可用状态，以及显式删除 iOS 持久设备标识四项能力。契约 `IDevice` 归 GameInterface，平台选择与实现归 GameSDK 的 `Hub/Device`；项目组合入口创建实例并将接口交给消费者。本模块是独立基础能力，本次不接入具体游戏场景、账号系统或广告业务。

框架约束见 [GameSDK README](../../../README.md)、[GameInterface README](../../../../GameInterface/README.md)及 [GameHub 组合使用](../../../../GameHub/README.md#组合使用)；文档和交付遵循[文档组织规范](../../../../../Docs/Project/06_文档组织规范.md)、[模块组织与交付规范](../../../../../Docs/Project/08_模块组织与交付规范.md)及[工程实施与验收标准](../../../../../Docs/Project/05_工程实施与验收标准.md)。接口、算法、平台接线、失败终态和验证方法由[实现跨平台设备服务](Tasks/实现跨平台设备服务.md)完整规定。

## 行为与验收

| 情境与前提 | 要求与可判定结果 |
|---|---|
| 项目在 Unity 主线程创建服务 | 获得新的 `IDevice` 实例。Editor 始终使用通用实现；Android、iOS Player 使用各自实现；其他平台使用通用实现。创建不读取标识、不触发权限请求。平台适配类型不暴露给消费者。 |
| Android 读取设备标识 | 支持 Android 8.0/API 26 及以上；每次由调用方在 Unity 主线程读取 `SystemInfo.deviceUniqueIdentifier`，有效值原样返回。`null`、空字符串或 `SystemInfo.unsupportedIdentifier` 抛 `InvalidOperationException`，错误消息不含标识值；本模块不缓存、不拼接签名、不重哈希或通过自定义 JNI 获取设备 ID，也不硬编码返回值长度。 |
| iOS 首次读取设备标识 | 从本次方法调用的参数字典解析 Keychain 定位配置；缺失或无效参数先报错，不访问 Keychain。仅当对应项不存在时生成并持久保存大写、带连字符的 UUID；成功保存后返回。权限、访问或存储失败不得当作不存在，也不得返回未持久保存的新值。 |
| iOS 再次读取、重建服务或重启应用 | 同一 Keychain 项存在时原样返回非空、不含 NUL 的有效 UTF-8 值，不要求历史值符合 UUID 格式，不自动重建、覆盖或记录该值。并发创建碰到已有项时重读；损坏值或无法重读的冲突明确报错并保留原数据。 |
| 项目维护 iOS 定位参数 | 每次读取或删除都由调用方传入字典，沿用相同 `account`、`service`、`identifier` 才能定位同一项；`description` 仅用于创建。模块不保存字典或配置，不派生默认键。Account 与 Service 形成主要唯一键，Identifier 是查询筛选，不承诺仅改变 Identifier 可建立独立项。需要隔离时使用不同 Account 或 Service。卸载重装后的保留由系统、签名与 Keychain 环境决定，不承诺永久唯一或永远保留。 |
| 主动删除 iOS 设备标识 | 仅删除本次参数字典定位的项；不存在视为成功，重复删除安全。删除成功后以相同定位参数再次读取创建并保存新值。删除失败明确报错，不伪造成功；非 iOS 忽略字典，删除是无副作用操作。 |
| Editor 或其他平台读取设备标识 | 原样返回 `SystemInfo.deviceUniqueIdentifier`，包括 Unity 的不支持标识；仅将 `null` 归一化为空字符串。不派生、缓存或宣称其跨安装稳定。Android 与通用实现均忽略方法参数字典。 |
| Android 读取广告能力 | 每次查询 Google Advertising ID 信息。仅在用户未限制广告跟踪且 ID 非空、非全零时返回 ID / `true`；受限或无有效 ID 返回空字符串 / `false`。库缺失、Google 服务不可用或连接失败须报错，与合法不可用结果区分。 |
| iOS 读取广告能力 | iOS 14 及以上只有 ATT 状态为 Authorized，iOS 13 使用系统广告跟踪开关；同时要求 IDFA 非空、非全零。满足时返回 IDFA / `true`，否则返回空字符串 / `false`。模块不请求 ATT 权限，也不改变同意状态；项目在自身流程处理权限。 |
| Editor 或其他平台读取广告能力 | 返回空字符串 / `false`，不请求平台广告服务。 |
| 重复调用与线程 | 不缓存设备或广告结果，不建立后台任务。设备 ID 读取、删除及 iOS/通用广告查询由调用方保证在 Unity 主线程执行，不承诺跨线程必抛或任意线程安全。只有 Android 广告查询强制拒绝实例创建线程和 Java UI 线程，并在访问 Google 服务前报错。不加锁、内部等待或调度。两次独立广告方法查询不构成原子快照，期间权限或系统状态改变可导致结果不同。 |
| 平台调用结束或失败 | 释放本次产生的 JNI 包装对象、原生字符串及 Core Foundation 资源。没有需消费者释放的长期原生资源；不要求 `IDisposable`，无标识明文日志。 |

## 接入与边界

项目组合入口通过无参 `DeviceService.Create()` 显式组装。`IDevice.GetDeviceId` 与 `DeleteIosDeviceId` 接受可省略的 `Dictionary<string, object>`；iOS 调用必须提供合法定位参数，Android 与通用实现忽略该字典。两个广告方法仍无参，iOS 广告查询不需要 Keychain 参数。参数字典由调用方持有，调用期间不得并发修改；模块仅将本次已知键解析为局部不可变值，不保存供后续调用使用。业务仅持有 `IDevice`，不依赖平台或内部配置类型；宿主负责使用范围、线程安排、权限配置与异常处理。

项目已确认处于未出包 Demo 阶段，Android 最低支持版本为 8.0/API 26，见[项目定义](../../../../../Docs/Project/01_项目定义.md#已确认的边界)。Android 设备 ID 采用 Unity 属性，不保留参考工程的设备 ID Java 插件、签名拼接或 SHA-256 算法，也无需兼容参考实现的 64 字符 ID。设备 ID 不依赖 Google 广告库；使用广告能力的宿主须自行提供兼容的 Google Advertising ID 库、所需 AD_ID 权限及广告 JNI 裁剪保留配置，本模块不自动管理这些构建依赖。

本次保留四个同步方法的能力及方法名，接口名统一为 `IDevice`，工厂名为 `DeviceService`；`IOSKeychainOptions` 仅是内部参数解析结果，不对外暴露配置入口。不提供旧 `DeviceIdUtil` 静态门面或 `IDeviceUtil` 别名，不迁移旧项目的全局配置中心、通用加密库和单例，不引入新的账号标识、设备指纹或权限编排能力。

设备标识的连续性取决于平台、签名与配置。Android 8.0+ 同设备、同用户、同签名的普通卸载重装应保持稳定，但不承诺永久唯一；恢复出厂、用户或签名变化，以及从旧版本 OTA 升级 Android 8.0 前已安装应用的历史例外，会影响连续性，详见 Task 的官方依据与边界。iOS 仅在旧项仍存在且可访问、定位配置一致时沿用旧值。广告标识可被系统或用户重置，与本模块持久设备标识相互独立。
